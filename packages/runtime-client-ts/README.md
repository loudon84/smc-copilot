# @smc/runtime-client

Generated TypeScript client for SMC Copilot Runtime API.

## Rules

- `src/generated/` is machine-generated. Do not edit by hand.
- Desktop must import from `@smc/runtime-client` only (public facade).
- Only Electron Main Process (or trusted local service) may construct a token-bearing client.

## Generate

```bash
npm run contracts:generate
npm run client:generate
```
