# ADR-036: OPSI Real Hermes Release + Installed-Controller Dispatch

## Status

Accepted (OPSI v1.7 engineering). Windows 10 live client-deployment remains `not_proven` until operator signoff. Cursor/CI must not write `proven` or `GO`.

## Context

ADR-035 installed a ProgramData Endpoint Controller skeleton. The Product still treats `productVersion` as Hermes version, copies unsigned ZIP as a “release”, hashes Controller revision text, verifies Ed25519 with system Python, mutates from OPSI cache after install, and records `HERMES_HOME` without injecting it into the Gateway task.

## Decision

1. **Three version axes are independent.** OPSI Product `1.7.0` / package `1`, Controller revision (monotonic), and exact Hermes runtime version. Action preflight uses release catalog membership + compatibility, never `productVersion == hermesVersion`.
2. **Release trust root is a signed `smc.opsi.product-release.v1` index** binding Product/package, Controller envelope, Runtime v3 envelope(s), verifier digest, and source/build identity. Production keys are never autogenerated; smoke uses `TEST-ONLY` keys and cannot satisfy Live Gate.
3. **Self-contained Windows verifier** ships in the Product/Controller bundle. Bootstrap pins its digest before execution. System Python, PATH Hermes, and online package install are forbidden on the production verify path.
4. **Controller install is signed and fail-closed.** Canonical digest is recomputed from the file set. Manifest signature, exact path/size/hash, ACL read-back, and atomic `current`+`previous` are required. Tamper or verify failure keeps the previous pointer.
5. **Thin OPSI cache bootstrap** only validates the request, verifies/installs/rolls back the Controller, and dispatches the installed entrypoint. After install, setup/update/status/recover/uninstall must not call `%ScriptPath%`.
6. **Gateway starts through `Start-SmcHermesGateway.ps1`**, which sets `$env:HERMES_HOME` and binds the exact active CLI/profile/bind/port. Task Action never invokes Hermes CLI directly.
7. **Build and publish are separate.** CI/stage emit `.opsi` inventory; `opsi-package-manager` is operator-only. `v1.7-client-deployment-release` is a mandatory Production Gate alongside v1.5 re-entry and v1.6 controller. GO does not authorize ≤100 rollout.

## Consequences

- Fake/smoke/fixture evidence cannot mark a release live-eligible or a Live Gate GO.
- Engineering may land while Live remains NO-GO.
- Subsequent Production Rings still follow ADR-034 Re-entry.
