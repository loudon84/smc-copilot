# Agent Development Workflow

`Solution Draft → PRD-DRAFT → PRD Review → PRD-APPROVED → Plan → Plan Review → PLAN-APPROVED → Implement → Test/Review → review-staged → Commit`

Canonical skills are in `.agents/skills`; `.cursor/skills` and `.cursor/references` are generated by `tools/agent-skills/sync_agent_skills.py`.

上游技能保留原始 `../../references/<name>` 链接；同步校验会将其映射到 `.agents/references/upstream/<name>`（Cursor 对应 `.cursor/references/upstream/<name>`），不改写上游 SKILL 内容。

For a non-trivial change, run grounding first, review the PRD independently, converge only a PASS result, then create a plan from the approved PRD. Use the existing `review-staged` skill before commit.
