# v1.3 Depot attestation

Attestation is produced by the trusted OPSI-native import pipeline or an allowlisted Operator signer. Control only verifies:

- depot id
- productId / productVersion / packageVersion
- artifact digest
- issuer on allowlist, not revoked
- generated/expiry window
- signature length and evidence ref

Mismatch, expiry, or revoke writes quarantine + global freeze. Control never emits a “copy complete” certificate.
