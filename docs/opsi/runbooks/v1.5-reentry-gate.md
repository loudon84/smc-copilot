# v1.5 signed Production Re-entry Gate

Import is the only production unfreeze path.

1. Operator Evidence binds v1.4 Windows 10 Clean Endpoint, accelerated Pilot, rollback summary, artifact digest, target/depot scope, and expiry.
2. Release Owner, Endpoint Ops, and Security Owner sign the same canonical payload with allowlisted Ed25519 keys.
3. `POST /api/v1/opsi/live-gates/import` verifies signatures. The service never self-signs GO.
4. `GET /api/v1/opsi/live-gates/v1.5-production-reentry` returns the persisted envelope.
5. `POST /api/v1/opsi/live-gates/{gate_id}/revoke` immediately blocks start/stable/next Ring and pauses running production campaigns.

Forbidden unfreeze paths:

- test seed in `SMC_OPSI_ENV=production`
- request body `decision=GO` without valid triple signatures
- `SMC_OPSI_PRODUCTION_GO=GO`

Cursor/CI must not write `proven` or `GO`.
