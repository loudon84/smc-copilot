# v1.3 Freeze and clear

Any of Incident Commander, Security, Release, or Endpoint Ops may set a global freeze. New production mutations stop at claim and dispatch. Reconcile, health, and approved rollback continue. Gateway/Work are not stopped.

Clear requires:

- root cause closed
- fresh preflight
- Release Owner + Endpoint Ops dual approval (not the freeze setter alone)

Critical causes (secret, owner, signature, false success, rollback failure, P0/P1) auto-freeze.
