# v1.6 Two-phase uninstall

1. Online user: quiesce exact Gateway task.
2. Offline user: disable/delete managed tasks; record residual evidence. Unknown residual → `UNINSTALL_BLOCKED`.
3. Delete Controller/runtime/desired/managed files. Keep user `.hermes` data.
4. Restore previous owner, or delete an empty owner file. Do not leave `hermes=opsi`.
5. Thin OPSI wrapper self-cleans after Controller exit; keep tombstone until read-back.
6. Clean reinstall starts from ABSENT.
