# v1.2 Rollback drill

Reuse v1.1 signed Action/Result/health/Work smoke. Do not implement cross-provider handoff. Baseline owner must already be `opsi` (preflight fail-closed otherwise).

## Scopes

| Scope | Behavior |
| --- | --- |
| `target` | Restore frozen baseline on one mutated endpoint |
| `batch` | Restore mutated targets in one batch |
| `campaign` | Restore all mutated targets in reverse batch order |

Rollback failure is a terminal gate: pause, no further rollout, Campaign `FAILED` if restore cannot complete.

## Drill sequence

1. Canary inject or real failure → auto pause, fencing token blocks queued dispatch.
2. Target rollback on one mutated host; verify checksum, owner, Gateway, Work reconnect evidence.
3. Batch rollback on the current dispatched batch.
4. Campaign rollback remaining mutated hosts.
5. Archive evidence; do not delete failed targets or rewrite snapshot/history to pass metrics.
