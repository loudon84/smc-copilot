# v1.7 Release key / provider

Production signing uses an external Ed25519 key reference (file or HSM/secret provider). Builders must not autogenerate a production private key.

Smoke/CI uses `TEST-ONLY-ed25519` and writes keys only under `--dest`. Source `CLIENT_DATA/keys/release-public-key.pem` is never rewritten.

Rotation: publish a new Product package with the new public key and a new release index signature. Previous Controller `current.json` remains valid until the next verified install. Do not place private keys in `.opsi`.
