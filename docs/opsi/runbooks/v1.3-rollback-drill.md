# v1.3 Rollback drill

Scopes: target, depot, ring, campaign.

Campaign rollback runs rings in reverse, each ring under Depot rate budget. Baseline Product/package/artifact/config and current Depot attestation must exist. Terminal `ROLLED_BACK` waits for Action Result, ProductOnClient read-back, Gateway probe, and Work smoke. Failure writes a terminal Gate and global freeze. Do not continue stable/GO.
