# v1.3 Ring operation

Observation floors: Ring 0 = 24h, Ring 1/2 = 12h, Ring 3 = 24h, Ring 4 = 14 days.

Progress a ring only when:

- every Depot lane in the current ring is PASSED
- observation deadline is persisted and elapsed
- fresh preflight is inside TTL
- triple approval is bound to the current campaign revision

Ring 0 any failure pauses the Campaign. Later rings pause the Depot lane first; two consecutive failures, three in 10 minutes, >2% failure, or unknown past reconciliation deadline pause the Campaign.
