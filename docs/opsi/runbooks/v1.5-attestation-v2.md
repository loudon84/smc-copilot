# v1.5 Depot Attestation v2

Attestation is canonical JSON + Ed25519. Control never copies files and never emits a “Depot copied” certificate.

Required bindings:

- depot / productId / productVersion / packageVersion
- artifact digest and runtime envelope manifest digest
- Hermes signer key id
- ProductOnDepot read-back digest and observedAt
- issuer / key id / algorithm=Ed25519 / expiry / evidence ref

Request bodies do not supply trusted public keys. Tamper, wrong key, expiry, revoke, or read-back drift quarantines the artifact and may freeze.
