# v1.2 Pilot NO-GO rules

Any item below blocks Pilot GO and v1.3 Production Rollout:

- v1.1 Live Gate is not `proven / GO`
- Secret leak or secret canary hit
- Owner conflict (`salt` / `runtime` / `direct`)
- False success or final Action `unknown` count ≠ 0
- Any rollback drill failure
- User Hermes data loss
- Healthy Gateway/Work stopped because Control or OPSI went offline
- Open P0/P1
- Metrics achieved by deleting failed targets, rewriting snapshot, or overwriting historical evidence
