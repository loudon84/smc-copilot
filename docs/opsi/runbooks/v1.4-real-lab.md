# v1.4 Real Lab service

Operator-attended. Lab assembly is `HttpOpsiJsonRpc` + company-internal PostgreSQL. Fake/Memory is `SMC_OPSI_ENV=test` only.

## Preconditions

- Isolated PostgreSQL database/schema and least-privilege role (not the OPSI Server database, not on Endpoints).
- `opsi_rpc_url` HTTPS; optional `opsi_rpc_ca_bundle`. Silent TLS bypass is forbidden.
- Copy `services/opsi-control/.env.example` → `.env`. Filling real opsiconfd credentials now reaches HTTP RPC.

## Start

```powershell
cd E:\git\smc-copilot\services\opsi-control
$env:SMC_OPSI_ENV = "lab"
uv run alembic upgrade head
uv run uvicorn main:app --app-dir src --host 127.0.0.1 --port 8787
```

`GET /ready` must show `rpcBackend=http`, `persistence=postgresql`, Alembic head, and worker state (`ok` or `disabled`). Restart the API and confirm inventory/action rows remain in PostgreSQL.

Workers may be disabled for debugging (`start_workers=false`); `/ready` must still report that fact. Production Campaign start stays frozen until a persisted `v1.5-production-reentry` GO exists.
