# v1.5 freeze and rollback

Critical owner/artifact/signature conflict writes a global freeze at claim and dispatch.

Rollback scopes: target, depot, ring, campaign. `ROLLED_BACK` requires Action Result + Product read-back + Inventory + Work evidence. Missing/stale evidence is UNKNOWN_BLOCKED, never false success.

Clear freeze only after dual approval and root cause closed. Then recover with a new signed Campaign if desired state changed.
