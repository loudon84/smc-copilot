# v1.7 Linux `.opsi` build

CI/build-only: `makepackage.py` stages a verified tree and may write a deterministic `.opsi` zip for inventory. Production Lab builders SHOULD run `opsi-makepackage` **on the verified stage directory** after `stage_release` succeeds.

Never invoke `opsi-package-manager -i` from CI. Record `.opsi` SHA256, identity digest, and release index digest in the evidence bundle.
