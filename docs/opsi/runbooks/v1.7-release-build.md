# v1.7 Real Hermes runtime / controller / release build

From the Product tree on a clean staging host:

```bash
python packaging/makepackage.py \
  --hermes-zip /secure/hermes-0.22.0-windows.zip \
  --hermes-version 0.22.0 \
  --signing-key-ref /secure/release-private.pem \
  --dest /secure/out
```

Outputs `smc-hermes-agent_1.7.0-1.opsi` plus `.sha256`. Inspect `OPSI/product-release.json`, Controller manifest, Runtime v3 manifest, SBOM, and provenance. Smoke (`--smoke`) writes `.smoke.zip` only and cannot satisfy Live Gate.

This script never runs `opsi-package-manager`.
