# v1.4 Task and owner recovery

Crash/recovery points for setup, update, uninstall, and rollback.

## Tasks

- Names: `SMC-Hermes-User-Bootstrap-{SID}` and `SMC-Hermes-Gateway-{SID}`.
- Register, then read back principal/action/trigger. JSON `task-manifest.json` cannot replace registration.
- Uninstall reads the manifest, removes both tasks, and read-backs absence.

## Owner transaction

- Machine phase: verify (Ed25519 before extract), stage, install, task definition. Version state stays `pending`.
- User phase: SID/home, absolute CLI exact version, `config check`, Gateway task/start/health.
- Commit `owner=opsi` only after health. Failures restore previous version/tasks/owner.
- Profile not ready is `RUNNING` / `USER_CONTEXT_PENDING`, not a successful owner commit.

Do not modify Machine PATH. Optional shims stay under the managed root.
