# v1.2 Approval, window, run, pause, resume, abort

## Roles

- Release Owner creates, freezes artifact/config, requests start.
- Endpoint Ops confirms inventory, window, and rollback execution.
- Security Owner required when signer, secret, or redaction policy changes.
- Creator cannot satisfy both Release Owner and Endpoint Ops.

Approvals bind Campaign revision. Frozen-field changes invalidate prior approvals. Body `actor` / `role` / `go` are rejected; identity comes from the token.

## Window

Workers dispatch mutations only inside `windowStart`–`windowEnd`. Observation and result reconciliation continue outside the window.

## Commands

| Command | Notes |
| --- | --- |
| start | Requires immutable live gate `GO`, feature flag, dual approval, pilot artifact, fresh preflight |
| pause | Stops new Control mutations; healthy Gateway/Work keep running |
| resume | Pause cause closed, re-preflight, gate pass, dual approval |
| abort | Stops further mutation; rollback of mutated targets is an explicit flag, never silent |

Default `pilot_start_enabled=false`. Callers cannot bypass with `go=true`.
