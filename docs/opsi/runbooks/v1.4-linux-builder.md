# v1.4 Linux Builder

Real `.opsi` packages are built on an OPSI 4.3 Linux host with `opsi-makepackage`. CI `makepackage.py --smoke` writes `.smoke.zip` only, uses `TEST-ONLY` keys, and must not rewrite `CLIENT_DATA/keys/release-public-key.pem` or emit `.opsi`.

## Inputs (all required)

- Real Hermes Windows zip
- Canonical artifact manifest v2 (`entrypoint`, `cliSha256`, `cliVersion`, `keyId`)
- External signing key ref (Ed25519). The builder must not generate a release private key.

```bash
python packaging/makepackage.py --hermes-zip /secure/hermes-0.22.0-windows.zip --signing-key-ref /secure/release.key
# then on the Linux builder:
./packaging/build-real.sh
sha256sum *.opsi
```

Publish only to the Lab Depot and read back `productOnDepot`. Never install a smoke archive. Private keys never enter the Product tree, archive, or logs.
