# v1.6 Controller package / build

Smoke Controller is an executable PowerShell fixture under `infra/opsi/products/smc-hermes-agent/controller/`. It is not README-only.

```text
python infra/opsi/products/smc-hermes-agent/packaging/makepackage.py --smoke --dest dist
```

Smoke uses TEST-ONLY Ed25519 and must not rewrite `CLIENT_DATA/keys/release-public-key.pem`. Real `.opsi` is built on Linux with `opsi-makepackage`.

Controller revision is independent of `hermes_version`. Package revision is 3.
