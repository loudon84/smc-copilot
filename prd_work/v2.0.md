# SMC Copilot PRD v2.0

## services/runtime → Salt Minion Migration Feasibility

**版本**：v2.0  
**项目**：`loudon84/smc-copilot`  
**目标架构**：Salt Master + Salt Minion + SMC Hermes Extension  
**实施工具**：Cursor  
**实施原则**：先并行验证替代率，达到门槛后再退役 `services/runtime`

---

## 1. 项目背景

当前 `services/runtime` 已同时承担 Hermes 安装/升级、Gateway 管理、配置同步、Endpoint 注册、Desired State、资源同步、Job、诊断等 Endpoint Control Plane 能力，同时混入 Chat、Session、Attachment、Task、Approval、Kanban 等业务运行能力。

`apps/work` 已具备直接访问 Hermes Gateway 的通信基础，因此 v2.0 不再继续扩展 Runtime 的企业终端控制能力，改为验证 Salt Master / Salt Minion 是否可替代 Runtime 的 Endpoint Control Plane。

目标不是一次性删除 Runtime，而是完成：

1. Salt Minion 接管终端管理连接；
2. SMC Hermes Extension 接管 Hermes 安装、配置、Gateway、诊断；
3. `apps/work` 保持直接访问 Hermes Gateway；
4. 量化 Runtime API / Service / LOC 替代率；
5. 达到门槛后进入 Runtime 退役阶段。

```text
SMC Backend → Salt Master → Salt Minion → SMC Hermes Extension → Hermes
```

Salt Minion Python 与 Hermes Python 必须隔离：

```text
Salt Runtime != Hermes Runtime
```

Hermes 使用独立 Bundle / venv，禁止依赖 Salt 内置 Python。

- SHA-256
- Download

- Version Layout

- Rollback

```text

→ apply change
→ verify
```

State 只负责 Desired State 判断；实际操作调用 `smc_hermes` Execution Module。

## 23. 回退机制

PoC / Canary 期间保留 Runtime。

控制文件：

```text
%ProgramData%\SMC\control-owner.json
```

切回：

```json
{
  "hermes": "runtime"
}
```

回退步骤：

```text
1. Stop Salt managed Gateway action
2. control-owner=salt → runtime
3. Start Runtime Service
4. Runtime Reconcile
5. Gateway Health Check
6. apps/work Reconnect
```

禁止同时启用两个 Owner。

## 24. Runtime 退役规则

v2.0 不删除 Runtime。

通过 Go 后进入后续版本：

```text
services/runtime
→ deprecated
→ read-only maintenance
→ archive
```

Chat / Task / Approval / Kanban 等非 Endpoint Domain 必须先明确迁移目标后才能删除 Runtime 仓库代码。

## 25. Cursor 实施约束

1. 禁止一次性删除 Runtime。
2. 禁止修改 Chat Transport 为 Salt Proxy。
3. 禁止 Salt 与 Runtime 同时管理 Gateway。
4. 禁止 Hermes 复用 Salt Python。
5. 禁止生产客户端 Git Clone Hermes。
6. 禁止 Pillar 明文保存 Secret。
7. 禁止把业务后台模型直接设计成 Salt SLS。
8. 新增 Salt 代码必须放 `infra/salt`。
9. 每个 Phase 必须独立提交并具备回退能力。
10. Characterization Test 先于 Runtime 删除。
11. `apps/work` Direct Mode 必须先通过 Chat/File/Session 回归。
12. Migration Inventory 达不到 Go 门槛时，停止 Runtime 退役。
