## 1. 目标

v2.0 已完成 `infra/salt`、SMC Hermes Extension、mock Pillar/Returner、`apps/work` Direct Hermes Mode、Runtime Freeze 和迁移覆盖率统计。

v2.1 进入真实客户端迁移：

1. 客户端安装真实 `salt-minion`，连接真实 Salt Master。
2. Salt Minion 成为员工 PC 唯一 Hermes Endpoint Control Agent。
3. 支持新电脑 Fresh Install 与现有 Runtime 客户端原地迁移。
4. Salt 接管 Hermes 安装、升级、配置、Gateway、健康检查、诊断。
5. `apps/work` 只连接 Hermes Gateway，不依赖 Runtime。
6. 迁移失败可恢复 `control-owner=runtime`。
7. Endpoint Control Plane API / Service 替代率达到 Go 门槛。

## 7. Windows Endpoint Bootstrap

`bootstrap.ps1` 输入：

```text
Master
MasterFingerprint
EnrollmentToken
BackendUrl
ArtifactBaseUrl
WorkMode=fresh|migrate
```

### 7.1 Endpoint ID

```text
bootstrap
  → POST Backend enrollment/start
  → backend 返回 endpointId
  → 写 %ProgramData%\\SMC\\endpoint-id
  → Salt MINION_ID = endpointId
```

Endpoint ID 不使用用户名，不依赖 hostname；安装后固定，用户切换不修改 Minion ID。

### 7.2 Salt 安装

```powershell
msiexec /i <salt.msi> /quiet /norestart `
  MASTER=<master> `
  MINION_ID=<endpointId> `
  START_MINION=""
```

安装后写：

```text
C:\\ProgramData\\Salt Project\\Salt\\conf\\minion.d\\smc.conf
```

```yaml
master: <master>
id: <endpointId>
master_finger: <masterFingerprint>
log_level: info
```

然后启动 `salt-minion` Windows Service。

## 8. Minion Enrollment

生产 Master 必须：

```yaml
auto_accept: false
```

禁止按普通 Grain 自动接受敏感 Endpoint，禁止客户端自己执行 Master key accept。

流程：

```text
1. Backend 创建 enrollment
2. Client 得到 endpointId + masterFingerprint
3. Client 安装并生成 Minion key
4. Client 上报 local minion public-key fingerprint
5. Salt Integration 查询 Master pending key fingerprint
6. 两端 fingerprint 一致
7. Salt Integration accept key
8. Client test.version / test.ping
9. saltutil.sync_all
10. state.highstate
```

Enrollment 失败不切换 Control Owner。

## 10. Windows User Binding

Salt Minion 运行在 LocalSystem。禁止使用 Salt Service 的 `USERNAME`、`USERPROFILE`、`LOCALAPPDATA`、`Path.home()` 作为企业用户身份或 Hermes Home SOT。

Pillar：

```yaml
smc:
  endpoint_id: ep_xxx
  user:
    user_id: u10086
    windows_account: "DOMAIN\\zhangsan"
    windows_sid: "S-1-5-..."
    profile_dir: "C:\\Users\\zhangsan"
  hermes:
    home: "C:\\Users\\zhangsan\\AppData\\Local\\hermes"
```

来源：

```text
apps/work login
  → SMC Backend
  → EndpointUserBinding
  → External Pillar
```

Grain 只上报 Device Facts，不再提供 Current User SOT。

## 12. Hermes Production Lifecycle

当前 `smc_hermes.install()` fixture copy 必须替换。

Pillar Artifact：

```yaml
smc:
  hermes:
    version: "0.20.0"
    artifact:
      url: "https://artifact/.../hermes-0.20.0.zip"
      sha256: "..."
      signature: "..."
```

安装：

```text
download
→ checksum
→ signature
→ staging
→ unpack
→ create isolated venv/runtime
→ verify hermes executable
→ version probe
→ activate
→ health
```

必须支持：`install / upgrade / rollback / inspect / version / health / doctor`。

允许提炼 Runtime 已验证的 artifact signature/checksum、archive policy、version layout、activation、executable validation、platform paths、gateway environment 到 Salt `_utils`；禁止运行时 import `services/runtime`。

## 13. Gateway Lifecycle

### 13.1 正式命令

当前 `gateway.sls` 改为：

```text
hermes gateway run
```

生成：

```text
%ProgramData%\\SMC\\bin\\hermes-gateway-<endpoint>.cmd
```

```cmd
set HERMES_HOME=<user-hermes-home>
"<hermes-exe>" gateway run
```

### 13.2 Scheduled Task

```text
name       = SMC Hermes Gateway
trigger    = OnLogon
user_name  = Pillar windows_account
force      = True
```

禁止 fallback `System`。没有有效用户时返回 `waiting_user_binding`，不得创建 System Gateway。

### 13.3 Restart

```text
task.stop
→ wait port closed
→ task.run
→ wait /health
```

不依赖 Gateway 内部自重启流程。

## 14. Runtime → Salt Ownership Handover

状态：

```text
PRECHECK
SALT_READY
HERMES_ADOPTED
OLD_GATEWAY_STOPPED
RUNTIME_STOPPED
OWNER_SWITCHED
SALT_GATEWAY_STARTED
WORK_VERIFIED
COMPLETED
ROLLBACK
```

迁移：

```text
1. Salt Minion install + enroll
2. sync_all
3. inspect existing Hermes
4. snapshot config / owner / runtime state
5. verify Salt can manage Hermes
6. stop current Gateway
7. stop/disable services/runtime
8. atomic write control-owner = salt
9. create/update Gateway Scheduled Task
10. start Gateway
11. /health
12. apps/work availability probe
13. write migration-complete marker
```

Control Owner 切换必须发生在 Salt 已经可执行之后。

回滚：

```text
stop Salt Gateway
restore config snapshot
control-owner = runtime
restore Runtime startup
Runtime reconcile/start Gateway
verify /health
```

v2.1 不卸载 Runtime 文件。

## 21. Real Windows Canary

v2.1 必须使用真实 Windows 11 PC/VM，不接受 fixture-only 结项。

### Case A — Fresh PC

```text
无 Runtime / 无 Hermes
→ Bootstrap
→ Salt Enroll
→ Hermes Install
→ Gateway
→ apps/work Chat
```

### Case B — Existing Runtime PC

```text
Runtime installed
existing Hermes data
→ migrate-runtime-to-salt
→ preserve Hermes Home
→ Runtime stopped
→ Salt owns Gateway
→ Chat/Session regression
```

### Case C — User Switch

```text
User A logout
User B login
→ Backend Binding update
→ refresh pillar
→ Gateway Task user/path update
→ A Secret 不可复用
```

### Case D — Salt Master Offline

```text
Master unavailable
→ Existing Gateway remains running
→ apps/work Chat remains available
→ New control jobs pending
```

## 26. Definition of Done

1. Windows 11 可通过机器级 Bootstrap 静默安装 Salt Minion。
2. Salt Minion 固定使用 3008 LTS 版本策略。
3. Minion 使用 `master_finger` 校验 Master。
4. 生产 Master `auto_accept=false`。
5. Endpoint 可完成受控 Key Enrollment。
6. 真实 Windows Minion 可 `sync_all` 并加载 SMC Hermes Extension。

8. Hermes 可 Fresh Install / Adopt / Upgrade / Rollback。
9. Gateway 以绑定 Windows 用户执行 `hermes gateway run`。
10. Gateway 不允许 System fallback。
11. Existing Runtime PC 可切换到 Salt Ownership。
12. 迁移失败可恢复 Runtime Ownership。
13. Salt 模式下 Runtime 停止，`apps/work` 正常启动。
14. Chat / Session / Files / Slash 无回归。
15. Salt Master 离线不影响现有 Hermes Chat Data Plane。
16. Endpoint API Replacement ≥85%。
17. Endpoint Service Replacement ≥85%。
18. Endpoint LOC Replacement ≥75%。
19. P0/P1 = 0。
20. 至少 5 台真实 Windows Endpoint 完成 Canary。

```text
PRD v2.2
Runtime Decommission + Salt Production Rollout
```
