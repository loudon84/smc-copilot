9. 统一 Chat Event Contract

  eventId: string;
  sequence: number;

  runId: string;
  turnId: string;
  segmentId?: string;

  instanceId: string;
  sessionId?: string;

  type: string;
  timestamp: string;
  payload: Record<string, unknown>;

事件类型：

SSE 规则
支持 Last-Event-ID；
每个 Turn 的 Sequence 单调递增；
服务重启后 Sequence 连续；
SSE 断开后自动重连；
Replay 后再订阅 Live；
相同 Event ID 只能应用一次；
Event Store 归 Serve；
Desktop 不再维护第二套 Runtime Event DB。

v1.6 Work Task 已具备持久 Event Store 和 SSE Replay，可复用其 Event Store、Scheduler 和 Recovery，不应重新实现另一套无关基础设施。
