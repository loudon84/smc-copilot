# 9. Phase 5：Runtime Restart Recovery

Runtime 重启时：

```text
queued
→ 自动恢复

pending
→ 自动恢复
```

对于：

```text
running
```

禁止无条件重新发送给 Hermes。

原因：

```text
可能已调用 Tool
可能已经产生业务副作用
无法确定 Provider 是否已执行
```

处理：

```text
running
→ interrupted
→ turn.failed
```

Error：

```text
RUNTIME_RESTARTED_DURING_TURN
```

Desktop 提供：

```text
Retry
```

由用户显式重试。

这是生产环境必须遵守的副作用安全边界。
