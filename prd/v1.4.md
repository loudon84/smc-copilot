# 9. Runtime 生命周期重新定义

## Production

Runtime 生命周期由：

```text
Windows Installer
       ↓
Windows Service / UserDaemon
       ↓
SMC Runtime
```

负责。

Desktop 关闭：

```text
Desktop Exit
```

不得导致：

```text
Runtime Exit
Hermes Exit
Task Exit
Expert MCP Gateway Exit
```

---

## Development

开发时：

```bash
npm run dev:runtime
```

负责 Runtime。

另一个 Terminal：

```bash
npm run dev:desktop
```

只负责 Desktop。

禁止：

```text
Desktop Electron
→ spawn Runtime
```

可选增加：

```bash
npm run dev:all
```

通过 Nx / shell 在仓库级同时启动两个 target。

但：

> 这是开发工具编排，不是 Electron Desktop 的业务能力。

# 15. Expert MCP Gateway 职责迁移

当前 Expert/Skill MCP Gateway 实际仍属于 Desktop Main。



而 Proxy 本身甚至由 Electron Main 创建 HTTP Server，并负责 Authorization Header、Device/Profile Header 和 JSON-RPC Forwarding。

这明显属于 Runtime。
