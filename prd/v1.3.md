# 11. Runtime Restart Recovery

Runtime Startup：

```text
queued
→ continue

claimed + expired lease
→ queued

running
→ interrupted
```

原则：

> 已开始产生副作用的 Task 不自动重复执行。

因此：

```text
running
→ interrupted
→ user/policy retry
```

除非：

```text
checkpoint 明确声明 safe_resume=true
```
