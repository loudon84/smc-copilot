# v8.2.0 Persistent Chat Workspace + Unified Session Catalog

范围：PR1（Chat 常驻）+ PR2（chat-workspace.db 持久化）+ PR3/PR4（Session Catalog + Sessions↔Chat 联动）+ PR6（强制 Electron E2E）。**不含** PR5（sessions.json 标题迁移与旧 API deprecation 清理），仅保留 PR2 内必需的 localStorage v1→db 迁移。

## 根因回顾（已核实）
- [`src/renderer/src/screens/Hermes/panels/HermesShell.tsx`](src/renderer/src/screens/Hermes/panels/HermesShell.tsx) 只渲染选中页 `<HermesPageLoader pageKey={pageKey} />`，切菜单即卸载 Chat。
- [`src/renderer/src/screens/Hermes/pages/Chat/MultiRunChatShell.tsx`](src/renderer/src/screens/Hermes/pages/Chat/MultiRunChatShell.tsx) 内部包裹 `ChatWorkspaceProvider`，随页面一起销毁；恢复只靠 `chat-workspace-state.v1` localStorage。
- Sessions 页经 `useHermesDefaultSessions` → `hermesDefaultApi.sessions.list()` → `window.hermesAPI.listCachedSessions()` 只读 `~/.hermes/desktop/sessions.json`，从不实时查 `state.db`。
- 已具备复用基础：[`src/main/utils.ts`](src/main/utils.ts) 的 `stateDbPathForProfile(profileId)`、[`src/main/chat-runtime/chat-runtime-store-router.ts`](src/main/chat-runtime/chat-runtime-store-router.ts) 的 per-profile 连接、[`src/main/chat-runtime/chat-runtime-ipc.ts`](src/main/chat-runtime/chat-runtime-ipc.ts) 的 `emitSessionStartedOnce`/`onDone`。

## PR2 — Main-owned chat-workspace.db 持久化（第 5、11、12 节）

**目标**：localStorage 不再是权威源；`~/.hermes/desktop/chat-workspace.db` 由 Main 写；重启恢复。

- Shared 契约 [`src/shared/chat-workspace/chat-workspace-contract.ts`](src/shared/chat-workspace/chat-workspace-contract.ts)：`ChatWorkspaceRunRow`、`ChatWorkspaceSnapshot`、`PatchRunInput`、channel 常量（`chat-workspace:list|open|patch-run|close-run|set-active|reorder|get-snapshot|changed`）。
- Main 模块 `src/main/chat-workspace/`：
  - `chat-workspace-db.ts`：打开 `join(HERMES_HOME,'desktop','chat-workspace.db')`，建 `chat_workspace` + `chat_workspace_run` 表（PRD §5.2）。
  - `chat-workspace-store.ts`：CRUD + 事务；`position` 维护顺序。
  - `chat-workspace-service.ts`：`getSnapshot / openRun / patchRun / closeRun / setActive / reorder`；`bindSessionToRun(runId, sessionId, title)`（收到 `session.started` 时事务内 `session_id` 落库并广播）。
  - `chat-workspace-ipc.ts`：`registerChatWorkspaceIpc(() => mainWindow)`，写入后 `mainWindow.webContents.send('chat-workspace:changed', snapshot)`。
  - `chat-workspace-migration.ts`：首次运行读取渲染层无法访问的 localStorage 不可行 → 迁移改为**渲染层触发**：Provider 首挂载时若 db 为空且本地有 `chat-workspace-state.v1`，调用 `open`/`patchRun` 批量导入并写 `chat-workspace-migration-v2` 标记。
- Preload：新增 [`src/preload/chat-workspace-api.ts`](src/preload/chat-workspace-api.ts)，在 [`src/preload/index.ts`](src/preload/index.ts) `exposeInMainWorld("chatWorkspace", ...)`；[`src/preload/index.d.ts`](src/preload/index.d.ts) 补类型（事件监听返回 unsubscribe）。
- Main 注册：在 [`src/main/index.ts`](src/main/index.ts) `registerChatRuntimeIpc(() => mainWindow)` 附近调用 `registerChatWorkspaceIpc(() => mainWindow)`。
- Renderer 接线：改造 `ChatWorkspaceProvider.tsx` — 保留 reducer 作视图缓存，但：
  - 初始化改为读取 `window.chatWorkspace.getSnapshot()`（异步 → 先 `Restoring chat workspace…` 占位），删除对 `loadChatWorkspaceState` 的依赖为唯一源（保留做迁移）。
  - 每个 mutation（open/close/patch/setActive/reorder/rename）dispatch 后再调对应 IPC。
  - 订阅 `chat-workspace:changed` 合并回 reducer。
  - 新增 `usePersistentChatWorkspace.ts` 封装 IPC + 迁移逻辑。
- Session 绑定：在 [`src/main/chat-runtime/chat-runtime-ipc.ts`](src/main/chat-runtime/chat-runtime-ipc.ts) `emitSessionStartedOnce` 内调 `chatWorkspaceService.bindSessionToRun(runId, sessionId)`（draft→session，更新 title，广播）。

**验收**：关闭重启后 Tab、顺序、Draft、Model、Session 绑定全部恢复。

## PR3 — Profile-aware Session Catalog（第 7、10 节 + FR-06 自动更新）

**目标**：Sessions 直读真实 `state.db`，多 Profile，无需手动 Sync。

- Shared [`src/shared/session-catalog/session-catalog-contract.ts`](src/shared/session-catalog/session-catalog-contract.ts)：`SessionCatalogItem`（PRD §7.3）、`SessionCatalogQuery`（profileId? / search / status / includeArchived）、channels（`session-catalog:list|open|rename|archive|delete|changed`）。
- Main `src/main/session-catalog/`：
  - `session-catalog-profile-reader.ts`：用 `stateDbPathForProfile(profileId)` 只读打开各 Profile `state.db`，查询 `sessions`+`messages`（复用 [`src/main/sessions.ts`](src/main/sessions.ts) 逻辑但**参数化 profileId**，不再固定 `HERMES_HOME/state.db`）。Profile 列表用 `window.hermesAPI.listProfiles` 对应的 main 侧 `listProfiles`。
  - `session-catalog-store.ts`：桌面 metadata 表 `chat_session_metadata`（PRD §10，建在 `chat-workspace.db` 内以复用连接）：custom_title/pinned/archived。
  - `session-catalog-service.ts`：`list(query)` = 合并各 profile reader + metadata + `chat_workspace_run.linkedRunId`；标题优先级：用户手工 → sessions.title → 第一条 user message → New Chat。`rename/archive/delete`。
  - `session-catalog-events.ts` + `session-catalog-ipc.ts`：`registerSessionCatalogIpc(() => mainWindow)`；广播 `session-catalog:changed`。
- 自动更新：`chat-runtime-ipc.ts` 的 `emitSessionStartedOnce` 与 `onDone`（turn.completed）后调 `sessionCatalogService.notifyChanged(profileId)` → 广播。
- Preload：[`src/preload/session-catalog-api.ts`](src/preload/session-catalog-api.ts) → `exposeInMainWorld("sessionCatalog", ...)` + `index.d.ts`。
- Main 注册同 PR2。

**验收**：首轮对话完成后 Session 在 1 秒内自动出现在 Sessions 页（不点 Sync）。
