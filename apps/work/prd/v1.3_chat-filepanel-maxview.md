# Chat 三栏布局优化方案

## 1. 源码判断

当前布局状态适合在 `Chat.tsx` 统一治理，不应让两个右侧面板各自决定显示关系。

现有 `SessionFilesPanel` 只接收 `profile`、`sessionId`、`onPreview`，组件内部直接渲染标题、搜索框及 Attachments、Context、Agent output 三个区块，没有显示/隐藏接口。([GitHub][1])

`FilePreviewPanel` 已经内部维护宽度，默认宽度为 `440px`、最小宽度为 `320px`，通过 pointer 事件拖动调整，并把宽度保存到 `localStorage`。因此新增全宽模式时应保留这套宽度状态，退出全宽后恢复原宽度，而不是把 `100%` 写入宽度配置。([GitHub][2])

现有 `FilePreviewHeader` 已有“显示目录、另存为、外部打开、关闭”四个动作，但没有最大化/还原按钮。([GitHub][3])

建议形成以下状态模型：

```text
Chat.tsx
├─ sessionFilesVisible
├─ filePreviewMaximized
├─ filePreviewState
└─ 三栏渲染关系
```

# 2. 目标布局

## 2.1 默认三栏

```text
chat-body
├─ chat-messages            flex: 1
├─ session-files-panel      240px
└─ file-preview-panel       用户拖动宽度
```

## 2.2 隐藏 Session Files

```text
chat-body
├─ chat-messages            自动占用释放空间
│  └─ 显示 Session Files 浮动按钮
└─ file-preview-panel
```

隐藏后不保留空白栏。

## 2.3 File Preview 最大化

这里不使用浏览器 Fullscreen API，而是采用 **Chat 工作区最大化**：

```text
chat-container
├─ chat-body
│  └─ file-preview-panel    absolute; inset: 0
└─ chat-input               保持显示
```

即：

* 覆盖 `chat-body` 全部宽度和高度；
* 不覆盖底部输入框；
* 不改变 Electron 窗口大小；
* 不进入操作系统全屏；
* 再次点击或按 `Esc` 恢复原三栏布局。

# 3. Chat.tsx 状态设计

在 `Chat.tsx` 增加：

```tsx
const SESSION_FILES_VISIBLE_KEY =
  "copilot:chat:session-files-visible";

const [sessionFilesVisible, setSessionFilesVisible] =
  useState<boolean>(() => {
    return (
      localStorage.getItem(
        SESSION_FILES_VISIBLE_KEY,
      ) !== "false"
    );
  });

const [
  filePreviewMaximized,
  setFilePreviewMaximized,
] = useState(false);
```

持久化 Session Files 显示偏好：

```tsx
useEffect(() => {
  localStorage.setItem(
    SESSION_FILES_VISIBLE_KEY,
    String(sessionFilesVisible),
  );
}, [sessionFilesVisible]);
```

File Preview 关闭时自动退出最大化：

```tsx
useEffect(() => {
  if (!filePreviewState.open) {
    setFilePreviewMaximized(false);
  }
}, [filePreviewState.open]);
```

由于项目会同时挂载多个后台 Chat 实例，键盘事件必须继续受 `active` 控制，只允许当前 Chat 响应：

```tsx
useEffect(() => {
  if (
    !active ||
    !filePreviewMaximized
  ) {
    return;
  }

  const handleKeyDown = (
    event: KeyboardEvent,
  ): void => {
    if (event.key !== "Escape") {
      return;
    }

    event.preventDefault();
    setFilePreviewMaximized(false);
  };

  window.addEventListener(
    "keydown",
    handleKeyDown,
  );

  return () => {
    window.removeEventListener(
      "keydown",
      handleKeyDown,
    );
  };
}, [active, filePreviewMaximized]);
```

# 6. FilePreviewPanel 改造

```tsx
  maximized?: boolean;
  onToggleMaximized?: () => void;
```

参数：

```tsx
  onRetry,
  onLoadMore,

```

## 6.2 最大化时禁用拖动

当前拖动宽度实现应继续保留，但增加保护：

```tsx
const startResize = (
  event: React.PointerEvent,
): void => {
  if (maximized) {
    return;
  }

  // 保留现有 resize 逻辑
};
```

最大化状态下不渲染拖动栏：

```tsx
{!maximized && (
  <div
    className={[
      "file-preview-resize-handle",
      isResizing
        ? "file-preview-resize-handle-active"
        : "",
    ]
      .filter(Boolean)
      .join(" ")}
    onPointerDown={startResize}
    title="Drag to resize"
  />
)}
```

## 6.3 根容器

```tsx
<div
  className={[
    "file-preview-panel",
    maximized
      ? "file-preview-panel-maximized"
      : "",
  ]
    .filter(Boolean)
    .join(" ")}
  style={
    maximized
      ? undefined
      : { width }
  }
>
```

这里的关键点是：

```tsx
maximized ? undefined : { width }
```

最大化时不改变 `width` state，也不覆盖当前保存的拖动宽度。退出最大化后自然恢复此前宽度。

```css

  pointer-events: none;
```


# 9. 交互规则

| 操作                 | 结果                                         |
| ------------------ | ------------------------------------------ |
| 隐藏 Session Files   | Chat 消息区立即扩展                               |
| 显示 Session Files   | 恢复固定宽度面板                                   |
| 打开文件预览             | 保持当前 Session Files 显示状态                    |
| 最大化文件预览            | 覆盖整个 `chat-body`                           |
| 最大化时拖动             | 不生效，拖动栏不显示                                 |
| 再次点击最大化            | 恢复原拖动宽度                                    |
| 按 Esc              | 退出最大化，但不关闭文件                               |
| 点击关闭               | 关闭预览并退出最大化                                 |
| 切换 Agent Output 文件 | 保持当前最大化状态                                  |
| 切换 Session         | 使用新 Session 的 Preview 状态；不得跨 Session 显示旧文件 |
| 重启应用               | 保留 Session Files 显示偏好，不保留 Preview 最大化状态    |

# 10. 不建议的实现

不要在最大化时执行：

```tsx
setWidth(window.innerWidth);
```

否则会污染当前保存的预览宽度。

不要调用：

```ts
element.requestFullscreen();
```

因为这会：

* 覆盖底部 Chat Input；
* 可能覆盖 Electron 标题栏；
* 改变退出键行为；
* 引入浏览器 Fullscreen 权限和状态；
* 不符合“只覆盖 chat-body”的要求。

不要把 `sessionFilesVisible` 放进 `SessionFilesPanel` 内部。隐藏面板后组件会卸载，组件自身无法提供重新显示入口。该状态必须由 `Chat.tsx` 持有。

## 11.3 手工验收

1. 打开一份 Markdown 报告；
2. 拖动 Preview 到约 600px；
3. 点击最大化；
4. Preview 覆盖 `chat-body`；
5. Chat Input 仍然显示；
6. 按 Esc；
7. Preview 恢复到约 600px；
8. 隐藏 Session Files；
9. Chat 消息区宽度扩大；
10. 点击浮动按钮恢复 Session Files。
