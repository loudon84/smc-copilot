



# Chat 用户 Prompt 导航实现方案

## 1. 方案结论

在 `chat-messages` 内增加一个 **Conversation Prompt Navigator（对话提问导航）**，只提取当前 Session 中的用户 Prompt，形成可折叠的右侧浮动目录：

```text
chat-body
├─ chat-messages
│  ├─ chat-messages-scroll
│  │  ├─ MessageList
│  │  └─ bottom sentinel
│  │
│  └─ prompt-navigator
│     ├─ Prompt 列表
│     ├─ 当前 Prompt 高亮
│     └─ 显示/隐藏开关
│
├─ session-files-panel
└─ file-preview-panel
```

**不要把 Prompt Navigator 设计成 `chat-body` 的第四栏。**  
它应归属于 `chat-messages`，使用浮动面板或折叠 Rail，避免与 Session Files、File Preview 继续争夺页面宽度。

当前 `Chat` 会为不同 Run 保留多个已挂载实例，只通过 `active` 控制当前可见实例和键盘行为，因此导航锚点必须包含 `runId`，不能只使用 Message ID，也不能在全局范围直接查找第一个匹配节点。citeturn230544view0

该功能只处理 Renderer 中已有的 `messages` 和滚动容器，不需要修改 Main Process、Preload、Hermes Agent 或 SQLite。现有架构也明确规定 Renderer 负责 UI 状态与流式展示，跨进程能力才需要通过 `hermesAPI`。fileciteturn0file4

# 2. 目标交互

## 2.1 默认状态

当当前 Chat 中用户 Prompt 数量达到 2 条时显示导航入口：

```text
┌───────────────────────────────────┐
│ Chat Messages                  ☷  │
│                                   │
│ 用户 Prompt                       │
│ Agent Response                    │
│                                   │
│ 用户 Prompt                       │
│ Agent Response                    │
└───────────────────────────────────┘
```

点击 `☷`：

```text
┌───────────────────────────────────┐
│ Chat Messages     ┌─────────────┐ │
│                   │ Prompts   × │ │
│                   │             │ │
│                   │ 1. 分析源码 │ │
│                   │ 2. 生成 PRD │ │
│                   │ 3. 检查代码 │ │
│                   │ 4. 优化布局 │ │
│                   └─────────────┘ │
└───────────────────────────────────┘
```

## 2.2 点击定位

点击某个 Prompt 后：

```text
Prompt Navigator Item
  → 找到对应用户消息锚点
  → 暂停自动滚动到底部
  → smooth scroll
  → 用户消息定位到视口上部
  → 消息短暂高亮
  → 导航当前项高亮
```

## 2.3 滚动联动

用户手工滚动 Chat 时：

```text
当前视口所属对话轮次
  → 自动计算对应的最近一个用户 Prompt
  → Prompt Navigator 高亮该项
```

这里不能只使用 `IntersectionObserver` 判断“用户气泡是否可见”。当用户正在阅读一段较长的 Assistant Response 时，对应的用户 Prompt 已经滚出视口，但导航仍应保持该轮 Prompt 为当前项。

正确规则：

```text
当前 Prompt =
最后一个位于视口顶部基准线以上的用户 Prompt
```

推荐基准线：

```text
chat scroll container top + 96px
```

# 3. 数据范围

Prompt Navigator 只收录：

```text
role === "user"
且属于 ChatBubbleMessage
且 content 非空或包含附件
```

不收录：

- Assistant 消息
- Reasoning
- Tool Call
- Tool Result
- Clarify Card
- Typing Indicator
- Slash Loader
- Agent Output 文件

当前 `ChatMessage` 已区分普通用户/Agent 气泡，以及 reasoning、tool_call、tool_result、clarify 等历史行；导航应只使用用户气泡。citeturn572466view3

当前 `MessageList` 还会过滤空气泡并把连续 Tool 行合并，所以不能使用渲染数组下标作为导航锚点；必须使用稳定的 `msg.id`。citeturn572466view1

# 5. Prompt 导航数据模型

创建：

```ts
// prompt-navigator/promptNavigatorUtils.ts

import type {
  ChatBubbleMessage,
  ChatMessage,
} from "../types";

export interface PromptNavigationItem {
  messageId: string;
  sequence: number;

  label: string;
  fullText: string;

  attachmentCount: number;
  timestamp?: number;
}

function isUserBubble(
  message: ChatMessage,
): message is ChatBubbleMessage {
  const kind = message.kind;

  return (
    message.role === "user" &&
    (!kind || kind === "user")
  );
}
```

## 5.1 Prompt 标题清洗

导航不应直接显示完整 Markdown。

```ts
function normalizePromptLabel(
  content: string,
): string {
  return content
    .replace(/```[\s\S]*?```/g, "[code]")
    .replace(/`([^`]+)`/g, "$1")
    .replace(/!\[[^\]]*\]\([^)]*\)/g, "[image]")
    .replace(/\[([^\]]+)\]\([^)]*\)/g, "$1")
    .replace(/^#{1,6}\s+/gm, "")
    .replace(/[*_~>|]/g, "")
    .replace(/\s+/g, " ")
    .trim();
}

function truncateLabel(
  content: string,
  maxLength = 72,
): string {
  if (content.length <= maxLength) {
    return content;
  }

  return `${content.slice(0, maxLength - 1)}…`;
}
```

## 5.2 构建导航项

```ts
export function buildPromptNavigationItems(
  messages: ChatMessage[],
): PromptNavigationItem[] {
  let sequence = 0;

  return messages.flatMap((message) => {
    if (!isUserBubble(message)) {
      return [];
    }

    const attachmentCount =
      message.attachments?.length ?? 0;

    const normalized =
      normalizePromptLabel(message.content);

    if (!normalized && attachmentCount === 0) {
      return [];
    }

    sequence += 1;

    const fallback =
      attachmentCount > 0
        ? `${attachmentCount} attachment${
            attachmentCount > 1 ? "s" : ""
          }`
        : "User prompt";

    return [
      {
        messageId: message.id,
        sequence,
        label: truncateLabel(
          normalized || fallback,
        ),
        fullText: normalized || fallback,
        attachmentCount,
        timestamp: message.timestamp,
      },
    ];
  });
}
```

# 8. 扩展 useChatScroll

当前 Hook 在用户向上滚动后暂停自动滚动，而发送新用户消息时会重新强制滚到底部。citeturn582795view0

点击导航项时必须在执行平滑滚动前，立即设置：

```text
userScrolledUpRef.current = true
```

否则在 Agent 仍然流式生成时，新 Chunk 可能再次把页面拉回底部。

## 8.1 返回接口

```ts
export interface ChatScrollController {
  containerRef:
    React.RefObject<HTMLDivElement | null>;

  bottomRef:
    React.RefObject<HTMLDivElement | null>;

  scrollToNode(
    node: HTMLElement,
    options?: ScrollIntoViewOptions,
  ): void;

  pauseAutoScroll(): void;

  resumeAutoScroll(): void;
}
```

## 8.2 实现

```ts
const pauseAutoScroll =
  useCallback((): void => {
    userScrolledUpRef.current = true;
  }, []);

const resumeAutoScroll =
  useCallback((): void => {
    userScrolledUpRef.current = false;
  }, []);

const scrollToNode = useCallback(
  (
    node: HTMLElement,
    options?: ScrollIntoViewOptions,
  ): void => {
    userScrolledUpRef.current = true;

    node.scrollIntoView({
      behavior: "smooth",
      block: "start",
      inline: "nearest",
      ...options,
    });
  },
  [],
);
```

返回：

```ts
return {
  containerRef,
  bottomRef,
  pauseAutoScroll,
  resumeAutoScroll,
  scrollToNode,
};
```

现有“用户发送新 Prompt 后回到底部”的逻辑继续保留。

## 9.1 当前 Prompt 计算

```ts
function findActivePrompt(
  container: HTMLElement,
  runId: string,
  items: PromptNavigationItem[],
): string | null {
  if (items.length === 0) {
    return null;
  }

  const containerRect =
    container.getBoundingClientRect();

  const activeLine =
    containerRect.top + 96;

  let activeId =
    items[0]?.messageId ?? null;

  for (const item of items) {
    const anchor = document.getElementById(
      getPromptAnchorId(
        runId,
        item.messageId,
      ),
    );

    if (!anchor) {
      continue;
    }

    if (
      anchor.getBoundingClientRect().top <=
      activeLine
    ) {
      activeId = item.messageId;
      continue;
    }

    break;
  }

  return activeId;
}
```

## 9.2 使用 requestAnimationFrame 节流

```ts
useEffect(() => {
  if (!active) {
    return;
  }

  const container = containerRef.current;

  if (!container) {
    return;
  }

  let frameId: number | null = null;

  const update = (): void => {
    if (frameId !== null) {
      return;
    }

    frameId = requestAnimationFrame(() => {
      frameId = null;

      setActivePromptId(
        findActivePrompt(
          container,
          runId,
          items,
        ),
      );
    });
  };

  update();

  container.addEventListener(
    "scroll",
    update,
    { passive: true },
  );

  const resizeObserver =
    new ResizeObserver(update);

  resizeObserver.observe(container);

  return () => {
    container.removeEventListener(
      "scroll",
      update,
    );

    resizeObserver.disconnect();

    if (frameId !== null) {
      cancelAnimationFrame(frameId);
    }
  };
}, [
  active,
  containerRef,
  items,
  runId,
]);
```

只允许 `active === true` 的 Chat 实例运行滚动监听。

# 10. 点击跳转

```ts
const highlightTimerRef =
  useRef<number | null>(null);

const jumpToPrompt = useCallback(
  (messageId: string): void => {
    const anchor =
      document.getElementById(
        getPromptAnchorId(
          runId,
          messageId,
        ),
      );

    if (!anchor) {
      return;
    }

    scrollToNode(anchor);

    anchor.classList.remove(
      "message-row-prompt-highlight",
    );

    // 强制重新触发 animation
    void anchor.offsetWidth;

    anchor.classList.add(
      "message-row-prompt-highlight",
    );

    if (
      highlightTimerRef.current !== null
    ) {
      window.clearTimeout(
        highlightTimerRef.current,
      );
    }

    highlightTimerRef.current =
      window.setTimeout(() => {
        anchor.classList.remove(
          "message-row-prompt-highlight",
        );
      }, 1400);
  },
  [runId, scrollToNode],
);
```

# 13. 宽度适配

Prompt Navigator 不应永久挤压消息正文。

推荐两种显示模式：

## 13.1 Chat 面板宽度充足

```text
chat-messages width >= 900px
→ 显示完整导航面板
```

## 13.2 Chat 面板变窄

当以下情况发生：

- Session Files 显示；
- File Preview 显示；
- 应用窗口缩小；
- 两个右侧面板同时打开；

自动进入 Compact 模式：

```text
chat-messages width < 900px
→ 默认收起为图标
→ 用户点击后以浮层方式展开
```

在 `Chat.tsx` 使用 `ResizeObserver`：

```ts
const chatMessagesRef =
  useRef<HTMLDivElement | null>(null);

const [
  promptNavigatorCompact,
  setPromptNavigatorCompact,
] = useState(false);

useEffect(() => {
  const element =
    chatMessagesRef.current;

  if (!element) {
    return;
  }

  const observer = new ResizeObserver(
    ([entry]) => {
      setPromptNavigatorCompact(
        entry.contentRect.width < 900,
      );
    },
  );

  observer.observe(element);

  return () => observer.disconnect();
}, []);
```

Compact 模式切换时，不要强制关闭用户主动打开的面板；只改变其样式。

```ts
const PROMPT_NAVIGATOR_KEY =
  "copilot:chat:prompt-navigator-open";

const [
  promptNavigatorOpen,
  setPromptNavigatorOpen,

  return (
    localStorage.getItem(
      PROMPT_NAVIGATOR_KEY,
```

持久化：

```ts
useEffect(() => {
  localStorage.setItem(
    PROMPT_NAVIGATOR_KEY,
```

```ts
const promptNavigationItems =
```

# 15. 与现有两个右侧面板的关系

## 15.1 Session Files

```text
Session Files 显示/隐藏
  ≠
Prompt Navigator 显示/隐藏
```

两者状态独立。

Session Files 隐藏后，Chat 面板变宽，Prompt Navigator 可自动从 Compact 恢复为正常宽度。

## 15.2 File Preview 普通模式

File Preview 打开后，Chat 面板可能变窄：

```text
ResizeObserver
→ Prompt Navigator Compact
```

## 15.3 File Preview 最大化

按照上一轮方案，File Preview 最大化时会覆盖整个 `chat-body`，底层 `.chat-messages` 不可见、不可交互，因此 Prompt Navigator 无需单独处理：

```text
File Preview Maximized
→ chat-messages visibility:hidden
→ Prompt Navigator 同时隐藏
```

退出最大化后恢复原状态。

# 16. 当前 Prompt 自动跟随

Prompt Navigator 自己有独立滚动条。

当当前项变化时，应确保对应导航项可见：

```ts
useEffect(() => {
  if (!activePromptId) {
    return;
  }

  const item = navigatorRef.current
    ?.querySelector<HTMLElement>(
      `[data-prompt-nav-id="${CSS.escape(
        activePromptId,
      )}"]`,
    );

  item?.scrollIntoView({
    block: "nearest",
  });
}, [activePromptId]);
```

由于 Message ID 可能包含特殊字符，也可以不用选择器，改为保存导航项的 Ref Map。

# 18. 性能要求

当前 Chat 在流式 Chunk 到达时会持续更新 `messages`，因此 Prompt Navigator 必须：

- 使用 `memo`；
- `onSelect` 使用 `useCallback`；
- 不解析 Assistant 正文；
- 不查询数据库；
- 不监听全局所有 Chat 实例；
- 只让 `active` Chat 注册 scroll 和 ResizeObserver；
- 不在每次 scroll 中调用 `setState` 多次；
- 使用 `requestAnimationFrame` 节流；
- 不使用 MutationObserver 扫描整个 Chat DOM。
