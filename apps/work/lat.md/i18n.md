# i18n

Work UI copy is authored in English as the only source locale. Feature work may add packages under `locales/en` only; other languages wait for administrator review and manual translation.

## Source and fallback locales

`en` is both the source of truth and the runtime fallback, so a missing translation never blocks shipping a feature.

[[src/shared/i18n/config.ts#SOURCE_LOCALE]] and [[src/shared/i18n/config.ts#FALLBACK_LOCALE]] are `en`. [[src/shared/i18n/index.ts#t]] reads the active locale first, then English, then the key itself. i18next is initialized with the same fallback. Non-English packages in `APP_LOCALES` may omit namespaces or keys; that gap is intentional until an administrator translates them.

## English-only authoring constraint

Feature implementation may add or edit only `locales/en`. Creating or updating other locale packages in the same change is forbidden.

Forbidden during feature work:

- Copying a new namespace file (for example `skillRun.ts`) into `zh-CN` / `ja` / `es` while adding English keys
- Machine-translating every `APP_LOCALES` entry in the same change as the English source
- Updating an existing non-English file because English gained a sibling key

Required during feature work:

- Add or change keys only in `src/shared/i18n/locales/en/<namespace>.ts`
- Wire a new namespace in [[src/shared/i18n/index.ts#resources]]; other locales may omit it or alias the English module
- Tests must assert English copy and English fallback, not a freshly generated non-English string

## Administrator translation

After English copy is inspected, an administrator translates by hand in a change that touches only non-English locale packages.

That follow-up change must not edit `locales/en` in the same diff. Missing keys keep serving English through [[src/shared/i18n/index.ts#t]] until the translated package lands.

## Simultaneous-creation guard

The guard fails when the working tree or the latest commit add/modify both `locales/en` and another `locales/<lang>` package.

Older mixed files already on the branch stay grandfathered. Deletions are ignored so a cleanup can drop a mistaken non-English file. The classifier is [[src/shared/i18n/source-locale-authoring.ts#classifyLocalePackageChanges]]; `npm run guard` and [[i18n-tests]] enforce it.
