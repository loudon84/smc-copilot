# frontend Domain Pack

First production reference pack for `smc.ges.domain-pack.v1`.

Files:

- `pack.json` — capabilities and Plan extension contract.
- `activation.json` — deterministic Change Matrix matching rules.
- `policy-lock.json` — pinned/adopted external policy inventory.
- `upstream-sources.md` — provenance and adoption rationale.

No file in this directory owns Plan, Delivery, Evidence, Commit or Roadmap state.
